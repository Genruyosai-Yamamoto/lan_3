# LAN - Network Device Server

Convert any device with Python into a server that connects multiple devices on a single network.

## Overview

LAN is a lightweight, Python-based networking solution designed to enable seamless communication between multiple devices on a local area network. Whether you're building IoT applications, distributed systems, or need device-to-device communication, LAN provides a simple yet powerful framework to get started quickly.

## Features

- 🔌 **Easy Setup**: Convert any device with Python into a network server
- 🌐 **Multi-Device Support**: Connect multiple devices on a single network
- ⚡ **Lightweight**: Minimal dependencies for quick deployment
- 🔄 **Simple Integration**: Straightforward API for device communication
- 📱 **Cross-Platform**: Works on any system with Python support

## Tech Stack

- **Python** (12.3%) - Core server logic
- **HTML** (87.7%) - Web interface and visualization
